This guide sets up a local development environment to build, run, and contribute
to Vibe Kanban Indie. If you only want to *use* the app, install it with
`npx vibe-kanban-indie` instead — see [Getting Started](/getting-started).

## Prerequisites

Before you begin, ensure you have:

- **Rust** (stable toolchain — the repository pins it via `rust-toolchain.toml`)
- **Node.js 18+** and **pnpm**
- **Git**

## Step 1: Clone the repository

```bash
git clone https://github.com/dexloom/vibe-kanban-indie.git
cd vibe-kanban-indie
```

## Step 2: Install dependencies

```bash
pnpm i
```

## Step 3: Run the dev environment

This starts the web app and the backend together, with ports auto-assigned:

```bash
pnpm run dev
```

<Check>
The terminal prints the URL to open. The board loads with your local projects
from `projects.toml`.
</Check>

## Common tasks

<Tabs>
<Tab title="Run">
```bash
pnpm run dev               # web app + backend (ports auto-assigned)
pnpm run backend:dev:watch # backend only, watch mode
pnpm run local-web:dev     # web app only
```
</Tab>

<Tab title="Check & test">
```bash
pnpm run check         # frontend + all backend Rust workspaces
pnpm run backend:check # all backend Rust workspaces
cargo test --workspace # Rust tests
```
</Tab>

<Tab title="Format & lint">
```bash
pnpm run format # cargo fmt (all workspaces) + Prettier
pnpm run lint   # ESLint + cargo clippy (all workspaces)
```
</Tab>
</Tabs>

<Note>
TypeScript types are generated from Rust with `ts-rs`. After changing a shared
type, regenerate with `pnpm run generate-types` — do not edit `shared/types.ts`
by hand.
</Note>
