In a world where software engineers spend most of their time planning and reviewing coding agents, the most impactful way to ship more is to get faster at planning and review.

Vibe Kanban Indie is built for this — the independent, self-hosted fork for a **single-developer process**: no team, no cloud, no auth. Use kanban issues to plan work privately on your own machine, then create workspaces where coding agents execute. Drive the whole crew from a terminal cockpit and Telegram.

We're not a coding agent, but work seamlessly with a handful of the most popular options like Claude Code, Codex, Gemini CLI and OpenCode.

```bash
npx vibe-kanban-indie
```

One command, all local. Describe the work, review the diff, ship it.
