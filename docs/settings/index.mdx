The Settings dialog provides a streamlined, tabbed interface for configuring Vibe Kanban.

## Accessing Settings

<Frame>
<img src="/images/settings-accessing.png" alt="Workspaces navbar showing the Settings gear icon with tooltip" />
</Frame>

- Click the **Settings** icon (<Icon icon="gear" />) in the Workspaces navbar
- Press `Cmd/Ctrl + K` and select **Settings**

## Settings Tabs

<Frame>
<img src="/images/settings-general.png" alt="Settings dialog showing the tabbed interface with General, Pipeline, Routines, Repositories, Agents, MCP Servers, and Telegram tabs" />
</Frame>

The settings dialog is organised into the following tabs:

| Tab | Description |
|-----|-------------|
| **General** | Appearance, default agent, editor, git, network access, notifications, and tags |
| **Pipeline** | The per-card pipeline stage definitions, edited as TOML |
| **Routines** | Recurrent routines that run on a schedule |
| **Repositories** | Repository scripts (dev server, setup, cleanup) |
| **Agents** | Agent profiles and variants |
| **MCP Servers** | Model Context Protocol server configuration |
| **Telegram** | Bridge status and a send-test-message button (read-only; the TOML is hand-edited) |

## Agents

<Frame>
<img src="/images/settings-agents.png" alt="Agents tab showing agent list, configuration variants, and settings options" />
</Frame>

Define and customise agent variants using a form-based interface. The Agents tab uses a finder-style two-column layout:

- **Left column (Agents)** - Available coding agents (Claude Code, Codex, Opencode, Cursor Agent, etc.)
- **Right column (Configurations)** - Different variants for the selected agent (Default, Opus, Approvals, Plan, etc.)

## MCP Servers

<Frame>
<img src="/images/settings-mcp.png" alt="MCP Servers tab showing agent selection, JSON configuration, and popular servers" />
</Frame>

Configure Model Context Protocol servers to extend coding agent capabilities with custom tools and resources.

- **Agent** - Choose which agent to configure MCP servers for (e.g., Claude Code)
- **Server Configuration (JSON)** - Edit the MCP server configuration directly in JSON format
- **Popular servers** - Click a card to insert a pre-configured MCP server into the JSON

<Card title="Connecting MCP Servers" icon="server" href="/settings/mcp-servers">
  Configure MCP servers within Vibe Kanban for your coding agents
</Card>

## Telegram

The Telegram tab is a read-only status panel for the send-only escalation bridge: it
shows whether the bridge is running and offers a **Send test message** button. The
bridge itself is configured in `~/.vibe-kanban/telegram.toml`, not from this tab.
